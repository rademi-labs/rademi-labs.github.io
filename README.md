# Rademi Labs LLC website

Public company website hosted with GitHub Pages at https://rademi-labs.github.io/.

Edit `index.html` and the files under `assets/`, then push to `main`. GitHub Pages publishes the repository root. `.nojekyll` keeps this a plain static site.

This repository contains public website content only. Never add Stripe secret keys, tax records, bank details, or other private company records. Payment processing belongs in a separate backend, not GitHub Pages.
